# График смен — сайт с базой

Статичный сайт (HTML + CSS + JS), общая база — Supabase.

## Как развернуть

1. Распакуйте архив и залейте **все файлы вместе с папкой `assets`** в корень репозитория (GitHub Pages) или на app.netlify.com/drop.
2. В Supabase выполните SQL со страницы «База».
3. Впишите URL и anon-ключ в `assets/config.js` (или скачайте готовый config со страницы «База»).

Страницы: `index.html` (график), `employees.html`, `objects.html`, `admins.html`, `database.html`, `data.html`.
Вход админа — кнопка вверху справа (по умолчанию admin / admin — обязательно смените).

## Сотрудники из других дивизионов (только на замены)

На странице **Сотрудники** внизу есть блок «Из других дивизионов» и кнопка «＋ Из другого дивизиона» (видна админу).

Поля: ФИО, дивизион/организация, короткое обозначение (например ЮГ), телефон, должность, № графика (0 = без своего графика), заметка.

Отличия от основных сотрудников:

- не привязаны ни к одному объекту и не показываются в его основном списке;
- не входят в счётчик «Сотрудников» и не создают своих смен;
- видны в блоке «Кого можно взять на замену» фиолетовыми чипами с пометкой дивизиона;
- после назначения замены появляются в графике отдельной строкой с тегом «другой дивизион»;
- если график = 0, человек считается свободным в любой день; если указан 1–14 — предлагается только в его выходные.

Замены синхронизируются между объектами: у «донора» ставится короткое обозначение объекта, куда он ушёл.


## Сотрудники: раскрывающиеся отделения и автовакансии

- Каждое отделение — свёрнутая строка; клик по названию раскрывает список людей.
- Сверху — выпадающее меню «Отделение» (все / одно / только другие дивизионы), поиск по ФИО/телефону и кнопки «Раскрыть всё / Свернуть».
- У объекта задаётся **штат — графики ставок** (например `1, 2, 1`). Ставка без сотрудника автоматически становится строкой «Вакансия» в графике и попадает в «нужно перекрыть».
- В списке сотрудников вакансии не показываются — только счётчиком в шапке отделения.

## Кандидаты на замену и «Близко к объекту»

- Блок пересобран: карточка на каждый день, внутри — аккуратные строки: аватар, ФИО, объект и адрес, расстояние, график и причина, кнопка «Назначить». Показываются первые 4, остальные — по кнопке.
- Переключатель **«Все кандидаты / Близко к объекту»** и поиск по адресу, объекту или ФИО.
- Сортировка всегда по близости: если у объектов заполнены координаты — в километрах, иначе по совпадению адресов («тот же адрес/улица»).
- Сверху блока — строка «Ближайшие объекты» с расстояниями.
- На странице «Объекты» у каждого филиала есть адрес, широта/долгота и штат, а также поиск по адресу и колонка «От текущего».


## Дизайн-система и тёмная тема

- `assets/styles.css` — единая дизайн-система в духе Linear / Vercel / Raycast: спокойные поверхности, тонкие границы, один акцентный цвет (индиго), мягкие тени, стеклянная шапка и модалки.
- Типографика: Inter / системный шрифт, отрицательный трекинг, табличные цифры (`tnum`) — числа в графике выровнены в колонки.
- Переключатель темы в шапке (☀ / ☾). Выбор хранится в `localStorage` (`grafik_theme`), при первом визите берётся системная тема; в `<head>` тема выставляется до отрисовки, чтобы не было белой вспышки.
- Тёмная тема — глубокий графит (#08090C) с пересчитанными цветами ячеек.
- Вся палитра и радиусы — CSS-переменные в `:root` и `html[data-theme="dark"]`.

## Компактный график без горизонтального ползунка

- Таблица переведена на `table-layout:fixed; width:100%` — дни сами делят ширину экрана, все 31 число влезает целиком.
- Высота ячейки 30 px, шрифт 11–12 px, узкие служебные колонки.
- На экранах уже 1200 px колонка «Телефон» автоматически скрывается, чтобы график оставался без прокрутки.
